# DevOps Assignment 2 — FA23-BAI-064

A responsive AI student portfolio used for the Git, GitHub, Docker, and GitHub Actions assignment.

## Project
The website is built with HTML and CSS and includes About, Skills, Projects, Labs, and Contact sections.

## Labs and Tools
- Git: Tracks project changes with version control.
- GitHub: Hosts the repository and supports collaboration through pull requests.
- Docker: Packages the website into a container image.
- GitHub Actions: Automates validation and Docker image builds.

## Run locally
Open `index.html` in a web browser.

## Docker
The website is served through Nginx in a Docker container on port 8080.

Webhook verification: push event test.
